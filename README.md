# 来客コールシステム（担当者指名）多言語対応版

Delta Chat内で利用する、事務所入口向けのWebxdc受付アプリです。来訪者が担当者を選んで呼び出すと、スタッフへ通知します。スタッフは「対応します」を押し、通常のDelta Chatから入口端末へ音声通話をかけます。

このREADMEは、`reception-select-1.0.4.xdc`に含まれるソースコードを確認して作成しています。実機での動作確認結果ではありません。

## バージョン

| 項目 | 値 |
| --- | --- |
| 対象ファイル | `reception-select-1.0.4.xdc` |
| manifestのバージョン | `1.0.4` |
| アプリ内のバージョン表示 | `v2026.10.14-c` |
| manifestのアプリ名 | 来客コールシステム（担当者指名）多言語対応版 |

## 主な機能

- 登録スタッフの名前を入口画面の呼出ボタンとして表示
- 指定スタッフへの通知、または「担当者がわからない／どなたでも」から全員へ通知
- 会社名・来訪者名の入力（任意、入力欄は最大30文字）
- 指名呼出しに60秒間「対応します」が付かない場合、全員へ再通知
- スタッフの対応表明と、入口画面への対応者名表示
- 来訪履歴の表示（新しい順に最大20件）
- スタッフ登録・解除、受付表示とスタッフ表示の切替
- 端末ごとの表示切替パスワード、呼び鈴の種類・音量設定
- 15言語の表示、アラビア語の右から左への表示、端末設定に応じた明暗表示

## 必要な構成

- 入口用のDelta Chatアカウントと、スタッフ各自のDelta Chatアカウント
- Webxdcと音声通話が利用できるDelta Chat端末
- 通知・通話に必要なネットワーク接続と端末の権限設定
- 入口とスタッフが参加する受付用チャット

1人で対応する場合は1対1チャット、複数人で担当者を選択する場合はグループチャットに、このWebxdcを共有します。

**入口とスタッフは、同じチャット内の同じ添付カードを開いてください。** 別の添付として送信したWebxdcとは、登録情報や呼出履歴を共有しません。新しい版を送った場合も、その新しいカードでスタッフ登録を確認してください。

## 初期設定

### 1. アプリを共有する

受付用チャットに`reception-select-1.0.4.xdc`を添付して送信します。入口と各スタッフの端末で、同じ添付カードから起動します。

### 2. スタッフを登録する

初回起動時はスタッフ表示です。「登録する」を押すと、そのアカウントのDelta Chat表示名が入口の担当者一覧に追加されます。

不要になった登録は「登録を解除」で取り消します。登録は在席確認ではないため、登録者が現在対応可能とは限りません。

### 3. 入口端末を設定する

入口端末で「受付端末にする」を押し、確認画面で「OK」を選びます。入口の担当者選択画面に切り替わります。そのアカウントが担当者として登録されていた場合は、登録を解除する更新を送ります。

### 4. 表示切替パスワードを変更する

初期パスワードは **`secret`** です。

スタッフ表示の「この端末の切替パスワードを変更」から、現在のパスワード、新しいパスワードの順に入力します。新しいパスワードは4文字以上です。入口端末では、受付表示に切り替える前に変更しておくと便利です。

パスワードは端末側のローカルストレージに保存されます。他の端末には共有されません。

## 来訪者の操作

1. 会いたい担当者の名前を押します。担当者が不明なら「担当者がわからない／どなたでも」を押します。
2. 会社名または名前を入力します。空欄でも呼び出せます。
3. 「呼び出す」を押します。
4. その場で待ち、音声通話の着信が来たらDelta Chatの着信画面で応答します。

同じ入口画面からの呼出しには10秒間の連打制限があります。送信後も選択画面は操作でき、10秒経過後には別の呼出しを送れます。

## スタッフの操作

1. 来客通知を確認し、受付用チャットのWebxdcを開きます。
2. 来訪履歴の対象行で「対応します」を押します。
3. Webxdcを閉じ、チャット一覧から入口アカウントとの1対1チャットを開きます。
4. Delta Chatの音声通話（Audio call）で入口へ発信します。
5. 来訪者が応答したら会話します。

グループで呼出通知を受けている場合も、通話は入口アカウントとの1対1チャットから行います。アプリ内の案内に出る「受付」はチャット名の例であり、アプリが通話先を自動選択するわけではありません。

「対応します」が受信されると、受付側には対応者名と着信への応答案内が表示されます。履歴は「対応中」の表示になります。通話終了を検知する機能や、履歴を「対応完了」に変更するボタンはありません。

## 通知と再通知

| 操作・条件 | 動作 |
| --- | --- |
| 担当者を指定して呼出し | 指定アカウント宛てに通知を要求 |
| 「どなたでも」で呼出し | 登録スタッフ宛てと、その他の受信者向けの通知を要求 |
| 指名呼出し後60秒間、対応表明の受信なし | 全員向けの再通知を要求 |
| 「対応します」を押す | 対応表明を共有し、チャットに案内を追加 |

通知内容には、入力された来訪者名が含まれます。登録スタッフ向けの通知は、そのスタッフが登録した表示言語を使います。その他の受信者向けの通知は日本語です。

**再通知の判定は、通話への応答ではなく「対応します」の受信有無です。** スタッフが先に電話をかけても、「対応します」を押していなければ再通知される場合があります。

再通知は受付側のJavaScriptタイマーで行います。画面を閉じた場合や、端末のバックグラウンド制限・スリープ中には実行が保証されません。また、受付画面の「お呼びしました」は送信処理後の表示であり、相手への配信・閲覧を確認した表示ではありません。

指名通知は通知先を絞る機能です。グループ内の呼出データや履歴を、指名相手だけに限定して公開する機能ではありません。

## 呼び鈴

スタッフ表示の「呼び鈴の設定」で、種類・音量を変更し、「試聴」で確認できます。

| 設定 | 内容 |
| --- | --- |
| ピンポーン | 初期設定 |
| ピンポンピンポーン（2回） | 2回の呼び鈴 |
| チャイム（4音） | 4音のチャイム |
| ベル | ベル音 |
| やわらかい音 | 柔らかい音色 |
| 鳴らさない | アプリ内の呼び鈴を無効化 |

音量の初期値は60%です。設定は端末側に保存されます。

**この版のコードでは、呼出しを送った端末で呼び鈴を鳴らします。受信したスタッフ端末で独自チャイムを鳴らす処理はありません。** スタッフが着信を知るための音・表示はDelta ChatとOSの通知設定に依存します。「鳴らさない」はDelta ChatやOS側の通知音を止める設定ではありません。

## 対応言語

日本語、英語、アラビア語、ドイツ語、スペイン語、フィリピノ語、フランス語、インドネシア語、韓国語、ネパール語、ポルトガル語、ロシア語、ティグリニャ語、ベトナム語、中国語。

画面上部で切り替えます。初回は端末の言語から選び、未対応の場合は日本語になります。管理用の一部表示（パスワード変更・呼び鈴設定など）は日本語と英語のみで、それ以外の表示言語では英語になります。チャットに追加される来訪・再通知などの案内は日本語です。

## 保存データと注意事項

- 端末側には、表示モード、表示言語、登録希望状態、切替パスワード、呼び鈴設定を保存します。
- スタッフの登録情報、来訪時刻、宛先、来訪者名、対応者名などはWebxdcの更新としてチャット参加者間で共有します。
- 来訪者名と呼出先は、チャットへの案内にも記録されます。コード内の`LOG_TO_CHAT`は`true`です。
- 履歴の「20件」は画面への表示上限です。古いチャットデータやWebxdc更新を削除する機能ではありません。
- パスワードは暗号化せずローカルストレージに保存しています。受付表示からスタッフ表示への簡易的な操作制限であり、端末全体のキオスク化や強固な認証ではありません。
- 複数スタッフが同時に「対応します」を押した場合の排他制御はありません。各端末は先に受信した対応者名を採用するため、表示の不一致や二重対応が起きる可能性があります。
- アプリは音声発信・応答・切断、マイク・カメラ、通話後の画面復帰を制御しません。
- 受付メッセージの自動消去や、無応答時に呼出状態を終了する処理はありません。新しい呼出しで表示が更新されます。

## 導入時の確認

1. 登録したスタッフが入口の担当者一覧に表示されること。
2. 指名呼出しと全員呼出しの両方で通知が届くこと。
3. スタッフ端末の画面ロック中やWebxdcを閉じた状態でも通知を確認できること。
4. 受付画面を開いたまま60秒待つと、未対応の指名呼出しが全員に再通知されること。
5. 「対応します」が入口画面に反映されること。
6. スタッフから入口へ発信し、入口で着信を確認・応答して音声会話できること。
7. 通話後に入口のWebxdcを再度開き、次の来訪者が操作できること。

担当者が表示されない場合は、同じ添付カードを開いているか、スタッフ側で「登録する」を押したか、更新が同期されているかを確認してください。通知が届かない場合は、Delta Chatの通知設定、OSの通知許可・省電力設定、通信状態を確認してください。

## ファイル構成

```text
reception-select-1.0.4.xdc
├── index.html      # 画面、スタイル、JavaScript、翻訳データ
├── manifest.toml   # アプリ名・バージョン等
└── icon.png        # アプリアイコン
```

`webxdc.js`はHTMLから読み込みますが、配布ファイルには含まれません。Delta Chat側から提供されます。アプリ独自の外部サーバーへの通信処理はなく、登録・呼出し・対応表明にはWebxdcの`sendUpdate()`と`setUpdateListener()`を使用します。
